# Проверка вакансий перед откликом

`pnpm shortlist:prepare` читает базу и локальный `private/enrichment-plan.json` (массив объектов jobId/url). До 40 публичных страниц за запуск; загрузка ограничена известными доменами, с паузой, таймаутом и остановкой запросов к доменам при 401/403/429. API Jooble не вызывается. Страницы — недоверенные данные, не инструкции.

Результаты: `private/enrichment-results.json`, снимок исходных вакансий, возможные повторы и очередь неполных описаний. Доступный HTML ещё не означает полное объявление или подтверждённую актуальность. Несовпадения города и идентичности заявки проверяются человеком.

Проверенные описания в `private/description-reviews.json` содержат jobId, исходный contentHash, description, sourceUrl и checkedAt. `pnpm match:profile` применяет их только при совпадении ID и хеша исходной записи. При изменении вакансии проверка устаревает и оригинальное описание снова используется. Нераспознанные требования остаются неопределёнными.

Повторы группируются только для просмотра по нормализованным работодателю и названию. Это возможные, а не доказанные дубликаты: города, разные заявки и все ссылки сохраняются. Удаления записей из базы нет.

Подготовленные CV, вопросы и локальный журнал находятся в private/applications/2026-10-01. Все начальные статусы — draft_for_review. Наличие файла не означает одобрение или отправку. Поля approvedAt, sentAt, response и followUpAt заполняются только по факту события. Автоматическая отправка не реализована этим этапом.

Личные документы, профиль, подтверждения и журнал не коммитить: private/ игнорируется Git. Запуск подготовки не изменяет документы CV и журнал откликов.
